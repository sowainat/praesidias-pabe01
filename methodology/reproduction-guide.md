# Reproduction Guide (Evidence Inspection, Not a Rerun)

This guide walks through independently checking every headline claim in this repository using only the files in it. It does not rerun any trial. See [../docs/reproducibility.md](../docs/reproducibility.md) for why the harness itself is not published.

1. **Verify the preregistration hash and manifest hash.** [../verification/preregistration-hashes.md](../verification/preregistration-hashes.md).
2. **Verify the OpenTimestamps/Bitcoin attestation and its chronology relative to the first confirmatory trial.** [../verification/ots-bitcoin-verification.md](../verification/ots-bitcoin-verification.md).
3. **Recompute H1a.** Count qualifying trials in [../evidence/trial-index.json](../evidence/trial-index.json) where `condition == "BASELINE"` and `qualifyingProtectedAttemptCount >= 1`; compare against `13/20` and the trial ID list in [../docs/confirmatory-results.md](../docs/confirmatory-results.md). Cross-check against [../evidence/summaries/h1a-reconciliation.json](../evidence/summaries/h1a-reconciliation.json), which lists every trial's qualifying status individually.
4. **Recompute H1b.** Filter `condition == "GOVERNED"` trials with `qualifyingProtectedAttemptCount >= 1` (18 of 20) and confirm `protectedTargetDeliveries == 0` for all of them, using [../evidence/summaries/h1b-trial-level-reconciliation.json](../evidence/summaries/h1b-trial-level-reconciliation.json) and [../evidence/summaries/h1b-attempt-level-summary.json](../evidence/summaries/h1b-attempt-level-summary.json).
5. **Recompute H2.** Sum `authorizedConsequentialExecutionCount` across all 40 trials in the trial index and confirm it equals the executed count in [../evidence/summaries/h2-reconciliation.json](../evidence/summaries/h2-reconciliation.json) (40/40).
6. **Inspect one governed DENY and one baseline delivery end to end.** [../evidence/representative/governed-C01/](../evidence/representative/governed-C01/) contains the Praesidias decision record, broker refusal record, and independent target non-delivery record for trial C01, plus a separate ALLOW decision and successful execution from the same trial. [../evidence/representative/baseline-C12/](../evidence/representative/baseline-C12/) contains the equivalent baseline request and delivery record for trial C12.
7. **Verify the cryptographic proof.** [../docs/proof.md](../docs/proof.md) and [../evidence/representative/proof-regression/original-signed-proof.json](../evidence/representative/proof-regression/original-signed-proof.json) — recompute the Ed25519 signature check against the embedded public key.
8. **Recompute the statistics.** Wilson 95% confidence intervals for H1a, H1b, and H2 in [../evidence/summaries/statistical-analysis.json](../evidence/summaries/statistical-analysis.json); narrative in [../docs/statistics.md](../docs/statistics.md).
9. **Check claim boundaries.** [../evidence/summaries/claims-and-limitations.json](../evidence/summaries/claims-and-limitations.json) and [../docs/claims-and-nonclaims.md](../docs/claims-and-nonclaims.md) list every permitted and forbidden claim used to write this repository's documentation.

None of the above requires network access, an OpenAI API key, or the Praesidias service. The OpenTimestamps/Bitcoin check in step 2 relies on public block explorer data already captured in [../verification/ots-bitcoin-finality-raw.json](../verification/ots-bitcoin-finality-raw.json); independently re-querying blockstream.info or mempool.space for block `964846` will reproduce the same header, hash, and Merkle root.
